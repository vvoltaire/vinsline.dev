## Features

- **Interactive 3D laptop** in the hero: drag to rotate, click to open or close, and press the glowing key to toggle the lights
- **Light and dark themes**
- **Projects section** with links to code and live demos
- **Outside the editor:** a photo gallery, guitar, a peace lily you can water, and art

## Tech stack

Next.js, TypeScript, React Three Fiber, Three.js, Tailwind CSS, shadcn/ui

## Running locally

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.
